1) Create a mysql database named "crud".
2) Import crud.sql to that database.
3) Install nodejs 25.0.0.
4) cd to backend. Run "npm install" to install dependencies.
5) Edit db.js file. Edit user and password if necessary.
6) Run "node index.js" to start backend server at port 8000. Browse http://localhost:8000 to check the backend server.
7) Go to app directory. Run "npm install" to install dependencies.
8) Run "npm run dev" to start frontend app at port 3000.
9) Browse http://localhost:3000 to start the frontend app.
